# 跨职业的人岗匹配设计

2026-10-24。下列分类和追问是产品设计归纳，不是招聘平台原样分类，不是心理测评或中国岗位需求的统计结论。

## 参考及使用边界

- [BOSS 直聘公开职业分类](https://www.zhipin.com/)：用于确认职业覆盖范围，包括教育培训、销售、运营、财务、翻译、市场公关等。
- [猎聘公开职位页面](https://www.liepin.com/)：用于交叉检查销售/BD、职能、金融及专业服务方向，未抓取个人求职信息。
- [O*NET Work Styles](https://www.onetonline.org/find/descriptor/browse/1.D)：参考其区分工作风格、活动、技能、环境的思路，不复制量表或权重。
- [O*NET 翻译职业页](https://www.onetonline.org/link/summary/27-3091.00)、[会计与审计职业页](https://www.onetonline.org/link/summary/13-2011.00)：参考同一职业仍包含不同任务。美国职业资料不能直接当作中国具体岗位的已确认要求。

## 三层对照

1. **愿不愿意长期做**：偏好、能接受的消耗和工作边界，1—5 或未知。
2. **现在有什么能力证据**：能力自述、项目/兼职/社团/实习经历、需要什么支持。不是客观能力测验。
3. **具体岗位实际怎么工作**：每天任务与占比、出现频率、考核、资格要求、支持资源和信息来源。

兴趣不等于能力，能力可发展；任务频率不等于能力门槛。不能用“能力 3 − 频率 5 = 不适合”这种公式。

## 职业方向与优先核实点

| 方向 | 值得讨论的任务特点（并非人人必须具备） | 关键差异和核实事项 |
| --- | --- | --- |
| 教育培训 | 讲解、倾听、反馈、课堂组织 | 授课/教研/教务/招生占比；续费、排课与家长沟通 |
| 销售 | 客户接触、协商、拒绝与回报周期 | 线索来源、无责底薪、回款提成、扣回与支持 |
| 地推 | 线下表达、现场执行、拒绝 | 外勤场所、有效线索定义、天气、安全与交通 |
| 运营 | 用户理解、协调、内容或数据复盘 | 内容/用户/活动/电商/客服；指标与值班 |
| 直播 | 镜头或现场表达、创意、反馈迭代 | 主播/场控/投流/剪辑；时段、GMV、账号肖像 |
| 商务拓展 | 长周期关系、谈判、多方协调 | 拓新/履约、资源、签约回款、应酬与垫资 |
| 翻译 | 语言、审校、专业资料理解 | 笔译/口译/本地化；领域、保密、审校和期限 |
| 公关市场 | 写作、信息判断、协调、表达 | 策划/媒体/活动/舆情；危机值班与审批 |
| 管理管培 | 协调、反馈、判断与任务跟进 | 是否有实际管理权；轮岗定岗和培养 |
| 职能支持 | 流程、细节、服务与冲突处理 | HR/行政/招聘/员工关系；考核保密和高峰 |
| 财务审计 | 细节核对、分析、规则与复核 | 月结忙季、资质、权限、差错责任与出差 |
| 金融 | 分析或客户经营，按细分任务而异 | 投研/风控/柜面/理财销售；资格合规与指标 |
| 咨询 | 研究、结构表达、客户协作 | 项目交付、差旅、反馈、导师和强度 |
| 设计传媒 | 创意、制作、修订和交付 | 自主权、改稿、版权、作品集和期限 |
| 服务与医护支持 | 服务沟通、规范、现场协作 | 具体资格、轮班、督导、安全与服务对象 |
| 技术工程 | 分析、细节、探索、协作 | 研发/实施/维护/现场支持；值班与评审 |
| 其他跨领域 | 直接按具体任务填写 | 不强制归类，不限制专业转向 |

## 当前实现

- careers.js：17 个职业方向、12 个跨职业任务维度和分类追问。不是平台正式 taxonomy，也不声称完整覆盖所有职业。
- schema.js：画像内愿意程度、能力自述与经历；Offer 内职业类别、细分任务、必要资格、培养支持、考核规则及 12 项任务强度。
- career-view.js：显示职业追问，以及用户输入形成的方向一致、偏好冲突待讨论或未知提示。
- 类别不自动写入需求、不改变原有六维分数。高频任务且明显不愿意只提示讨论，不直接淘汰。
- Prompt：输出结构化对照，要求解释可能消耗、已有证据、可学习部分和待确认条件；不依据专业、性格或人口属性限制职业选择。
- 未填的扩展字段不逐项堆入 Prompt；不以空白当中等。

## 下一步验证

请教育、销售、翻译、财务等不同背景用户试填，检查每类至少两个细分岗位。收集问题是否易懂、是否揭示实际取舍；在验证前不推出“职业匹配百分比”。
