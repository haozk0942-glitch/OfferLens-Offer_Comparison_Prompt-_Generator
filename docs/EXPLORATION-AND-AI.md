# 经历、可选探索与 AI 使用

更新时间：2026-10-24。

主流程：01 自我画像 → 02 Offer 信息 → 03 本地比较 → 04 生成 Prompt。

经历新增 12 项问题，围绕成就、消耗、外界反馈、重来一次、带教、管理、协作、冲突、取舍、底线、后悔和外部期待。可只填有关的问题；数据进入 Prompt，不自动改评分或诊断人格。

八字默认关闭。可输入已有四柱，或公历/农历出生资料（时间地点可不填）；本站不自动排盘。独立探索 Prompt 只用于文化反思，不输出职业排名。主职业 Prompt 默认不包含这些资料，需要用户额外勾选，且模块必须启用。出生资料与四柱按当前模式互斥输出。草稿导出仍包含填写资料，应自行保管。
