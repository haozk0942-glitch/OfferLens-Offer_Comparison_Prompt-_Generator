## 录入规则

- 所有新增字段选填，按组折叠；原有草稿导入时补空默认值，不替换已有信息。
- 当前工作可以是一个机会；最多 8 个。未落实机会可进入 Prompt 的等待策略，不能视为已可入职的确定选项。
- 原始薪资允许写 N+、范围、绩效条件；固定工资只填写已知数字。保证发薪月数不能包含未保证奖金。
- 只有明确保底年薪时可选择“直接填写税前年保证收入”；该口径与月薪 × 月数互斥，未选中字段不计入保证收入。
- 声称总包、餐房补、公积金、签字费、人才补贴、分期激励不自动汇总计分。尤其宿舍与房补互斥、多年激励、服务期及返还条件需明确。
- 995.5、8106 等不自动换算工时；周工时只填写明确了解或估计的数值。
- 公司性质、学校、层级、行业热度不直接加分；企业趋势、优缺点、传闻注明主观性和来源。
- 新字段进入 Prompt 的结构化数据，要求模型区分现实基线、已落实机会及在途机会，讨论首年/长期、生活代价、等待成本与核实事项。
- 本地六维评分仍是原型规则，新增细节主要用于 Prompt 分析，不假装已具备精确福利/税后/法律计算。
