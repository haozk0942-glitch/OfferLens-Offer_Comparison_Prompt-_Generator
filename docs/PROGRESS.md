# 项目进度

## 经历扩展、可选八字与 AI 指南

经历扩展为具体经历/环境偏好/现实取舍三组 12 项选填问题。八字默认关闭，可记录已有四柱或出生资料，不自动排盘；独立探索 Prompt 与主职业 Prompt 分开，主 Prompt 需主动勾选才加入。流程调整为 01 画像 → 02 Offer → 03 本地比较 → 04 Prompt。新增通用 AI 入口及核实、追问、交叉检查指南。31 项测试通过。

## 跨职业画像与人岗任务对照

参考 BOSS 直聘、猎聘公开类别及 O*NET 任务/风格框架，新增 17 个产品职业方向和 12 个任务维度。画像区分愿意程度、能力自述、经历证据；Offer 区分具体任务强度、资质、培养支持与考核。职业类别只提供核实问题，不代填需求、不改变六维总分。Prompt 加入人岗匹配分析；未填写扩展项不堆入 Prompt。28 项测试通过。设计与来源见 CAREER-MATCHING.md。

## 外派与出差条件卡片

选择国内或海外外派后显示独立卡片：国家/地区、具体城市、驻外时长、驻外补贴、接受程度及说明；选择需要出差后显示频率和说明。出差频率沿用个人画像的同一选项来源。切换为不需要后隐藏详情，保留草稿值以便切回恢复，但隐藏的外派/出差详情不送入 Prompt。23 项测试通过。

## 截图需求扩展

五张帖子截图已提炼为 schema.js 字段清单，映射说明见 SCREENSHOT-FIELDS.md。新增背景/等待条件及四组岗位细节，均选填并可折叠。支持 2—8 个机会，区分当前工作与未落实机会；总包和条件性福利不重复计入保证收入。支持直接填写保证年薪，与月薪口径互斥。22 项规则、迁移与 Prompt 检查通过。

## 2026-10-24 · 第一天

目标：建立本地可运行闭环，帮助用户认识自己、录入机会、解释取舍。

已实现：首页、画像、offer 录入、规则评分、结果解释、偏好调整、本地保存和导出。采用原生 ES Modules + CSS，零第三方依赖，降低首次启动门槛。后续组件复杂度增加时再评估迁移 React + TypeScript。

尚未实现：经历自动提取、每字段来源管理、自动效用锚点、奖金与工时情景控件、账号、八字、发布。

接下来请产品负责人体验示例，再填一组匿名真实案例。反馈格式：页面 → 操作 → 实际结果 → 希望怎样。优先修正问题难理解、字段难填写、评分不能解释的部分。
