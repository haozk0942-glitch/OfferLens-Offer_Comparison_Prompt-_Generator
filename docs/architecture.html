Evaluation 计算结果保证收入、底线、未知项、分项贡献、覆盖、范围、分数从当前输入重算，不单独保存；信息来源不直接加减分
Draft 草稿profile + offers + example浏览器 localStorage 单份；无账号或跨设备同步
Evidence / Snapshot独立证据、决策版本、复盘尚未实现未来扩展，不应误认为已经具备

03 · 技术架构

Node server.mjs（仅提供静态文件）
↓
index.html → styles.css + app.js（页面 / 事件 / 草稿）
app.js → engine.js（纯函数计算）
app.js ↔ localStorage / JSON 文件
engine.test.js → engine.js（六项规则检查）

所有业务计算在浏览器完成；无需安装第三方依赖。没有数据库、业务 API、模型请求或云端同步。
