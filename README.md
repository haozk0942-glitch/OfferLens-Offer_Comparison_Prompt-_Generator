# OfferLens · 知己择业

<img src="logo.svg" width="80" height="80" alt="OfferLens 绿色指南星标志">

**v0.1.0 体验版 · 无需 API Key · 无第三方运行时依赖**

面向应届生与初职求职者的 offer 决策助手。中文、手机优先、无需登录。

当前流程：**01 自我画像 → 02 Offer 信息 → 03 本地比较 → 04 生成 Prompt**。用户检查后将 Prompt 复制到自己使用的通用 AI，继续追问和分析。本站不调用模型 API。

![首页预览（界面迭代中，截图仅作示意）](docs/preview.png)

跨职业支持：17 个职业方向、12 个任务维度，个人愿意程度/能力经历与岗位任务强度分开记录；职业类别只提供追问，不自动加减分。详见 [CAREER-MATCHING.md](docs/CAREER-MATCHING.md)。

## 功能

已根据用户提供的五张求职截图增加可折叠的公司岗位、福利、作息、合同与个人取舍字段；支持当前工作和在途机会，最多 8 个。字段与截图映射见 [SCREENSHOT-FIELDS.md](docs/SCREENSHOT-FIELDS.md)。schema.js 为新增字段的单一清单，驱动默认值、表单、导入校验与 Prompt 输出。新字段主要进入 Prompt，不自动套用未经验证的评分。

- 城市按拼音排序下拉添加，支持多城市及手动输入；名单范围见 docs/CITY-DATA.md。
- 政治面貌、性别、学历、学校、专业均选填。
- 外派/海外意愿、外派目的地、具体接受情况、出差频率与上限检查。
- Prompt 本地生成、可编辑、复制与 txt 下载。默认省略公司名、学校名、性别与政治面貌；可选择纳入部分背景，自由文本需自行检查。没有自动上传。
- 经历与偏好包含成就、消耗、反馈、学习方式、协作冲突与取舍反思。
- 外派时展开国家/地区、目的地、驻外时长、补贴与接受情况；需要出差时展开频率，与个人接受上限比较。
- 八字探索为可选文化反思模块，不内置排盘，不参与评分，默认不进入主 Prompt。
- 新模块：model.js 管理字段和旧草稿迁移，views.js 管理表单，ui.js 管理控件，cities.js 管理城市名单，prompt.js 管理模板。

## 启动

需要 Node.js 18 或以上。在项目文件夹打开终端执行：

```sh
node server.mjs
```

浏览器访问 http://localhost:5173 。保持终端运行；按 Ctrl+C 停止。无需安装依赖，也不需要 npm。端口被占用时关闭此前启动的服务再试。

## 当前可用

- 首页与虚构案例体验
- 个人目标、底线、经历和六维权重
- 2—8 个机会，保证收入与浮动奖金分开；支持当前工作和在途机会
- 底线检查、匹配解释、未知信息与核实清单
- 调整偏好重新计算，本地自动保存及 JSON 导入导出
- 响应式手机布局

## 评分方法与边界

经济分 = 保证年收入 / 12 / 满意税前月均收入 × 100，上限 100。其余五维由用户的 1—5 分映射到 0—100。所有权重按总和归一化。默认权重只是可修改的初始设置，不是经过验证的职业测量模型。

缺失值不填中等分。已知项参考分按已知项权重重新归一，同时展示覆盖权重与未知项在 0—100 时的总分范围。这是情景边界，不是概率或置信区间。存在底线冲突、未知底线或缺失评分时不生成确定推荐。

城市按可接受列表匹配，兼容“杭州 / 杭州市”后缀差异；国内外派检查外派目的地，海外安排独立检查意愿。工时为用户估计。评分依赖用户输入，不自动判断公司文化或稳定性。经历仅保留为反思依据，MBTI 仅记录。性别、政治面貌、学校与八字不用于自动评分。暂未实现税费或股权估值、内置 AI 分析、八字排盘、账号或云同步。当前工具是体验版，不保证职业选择结果。

## 数据

数据存于当前浏览器 localStorage。不上传填写内容，未引入分析或第三方请求。共享设备使用后请清空；导出文件包含个人填写内容，请妥善保管。不同浏览器和访问地址的数据不自动互通。浏览器隐私设置或清理缓存可能导致记录丢失。

打开外部 AI 网站并粘贴 Prompt 后，资料处理适用对应服务的规则；本站不会自动发送资料。提交 Issue、截图或代码时请使用虚构案例，勿上传真实求职资料或个人草稿。

## 修改代码

| 文件 | 用途 |
| --- | --- |
| `app.js` | 页面导航、状态、本地保存、比较结果 |
| `views.js`、`ui.js`、`styles.css` | 表单、控件和样式 |
| `model.js`、`schema.js` | 草稿结构、字段定义、兼容迁移 |
| `engine.js` | 本地规则与计算 |
| `careers.js`、`career-view.js` | 职业方向和任务匹配讨论 |
| `mobility.js` | 外派和出差条件表单 |
| `prompt.js`、`exploration.js` | 主 Prompt、探索模块和 AI 指导 |
| `cities.js`、`logo.svg` | 城市选项和矢量标志 |
| `server.mjs` | 本地预览服务器 |

新增前端文件时需要同步更新 `server.mjs` 的静态文件允许列表。项目可以部署到静态网站托管服务；上传 GitHub 代码不会自动启用线上网站。
